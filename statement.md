# Project Statement

## Title
Student Management System

## Problem Statement
Educational institutions need a simple way to maintain student information and academic records. Manual record management can be time-consuming and error-prone.

## Objectives
- Store student information digitally.
- Add, search, update and delete student records.
- Store subject-wise marks.
- Calculate percentage, grade and pass/fail status.
- Generate performance statistics.

## Scope
The project focuses on basic student and academic record management using Python and CSV files.

## Target Users
Teachers, small educational institutions and students.

## Expected Outcome
A lightweight modular application for student records, academic results and analytics.
