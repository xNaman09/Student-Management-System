# Student Management System

A basic Python-based Student Management System using Google Colab and CSV storage.

## Objectives
- Manage student records
- Manage marks and results
- Generate academic reports
- Demonstrate modular Python programming

## Functional Modules
1. Student Management
2. Marks & Academic Management
3. Reports & Analytics

## Non-Functional Requirements
- Performance
- Usability
- Reliability
- Maintainability
- Error Handling
- Resource Efficiency

## Technologies
Python, Pandas, Matplotlib, CSV and Google Colab.

## Project Structure
database.py - CSV database operations
validation.py - Input validation
student_management.py - Student CRUD
marks_management.py - Marks and results
analytics.py - Reports and charts
main.py - Main application
requirements.txt - Dependencies
